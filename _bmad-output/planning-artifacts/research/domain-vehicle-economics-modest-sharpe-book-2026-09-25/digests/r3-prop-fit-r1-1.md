# r3-prop-fit-r1-1: Can a prop evaluation firm host an automated, multi-week-hold, Sharpe ~0.7 strategy?

Accessed 2026-09-25. Budget: 20 tool calls, all used. 9 primary firm pages hit (5 fetched in full, 4 seen only as search snippets because fetch returned HTTP 403).

**Short answer:** No futures evaluation firm checked allows a position to be held overnight, let alone over a weekend. Each firm's own help page (Topstep, Apex, Alpha Futures, Tradeify) says so directly; for TradeDay and Take Profit Trader the evidence is secondary. That rules out the strategy **by construction** at every futures firm, whatever their automation rules say. The only candidate found that allows multi-week holds is an **equity** prop firm: Trade The Pool's Swing accounts. Even there, automation is "beta" and needs the firm's approval. A 30% "best position" profit cap also conflicts directly with a strategy whose P&L comes from a few large winners.

## (C) Leads
- **Take Profit Trader "Swing PRO"**: the only futures-side hint of overnight holds. Check the takeprofittrader.com terms and help center (the zendesk pages returned 403 to WebFetch). Also check the ToS automation clause, weekend treatment and DLL.
- **Trade The Pool Swing + SignalStack beta**: ask TTP support three things. Does an open multi-week position count as "activity" for the 14-day inactivity timeout? Is API approval available for a low-frequency bot? How is the 30% "best position" ratio computed on a position held for weeks?
- Other equity prop firms allowing swing holds (e.g., other US stock prop programs): not searched because of the budget.
- Topstep XFA/Combine drawdown type (EOD trailing, per secondary sources) and monthly subscription/activation fees: not retrieved from the primary pages.
- The contrast between Apex's primary page and secondary sources on automation in evaluation. The primary text reads "all account types".
