# Account model demonstration inputs

These deliberately synthetic paths exercise phase transitions, payout requests and loss floors. They are software demonstrations, **not forecasts, backtests, expected returns, or claims that a strategy can produce these outcomes**. Dates are arbitrary future labels, not observations. Quantities are never scaled with capital. No capital transfer is recommended.

The positive path uses $400 net per traded day and a −$200 intraday minimum; the adverse path loses $500 per day. Both include costs in the hypothetical net input. Published account and API fees are additional modeled operating costs, pending actual invoices and written applicability. A demonstration ignores margin adequacy, tax and fill capacity, which remain unresolved.
