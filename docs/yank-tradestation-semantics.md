# TradeStation MNQ historical and prospective semantics

Research checked 2026-09-09. **HOLD_VALIDATION**. This report distinguishes provider documentation, repository observations and unresolved evidence. Public documentation was fetched without authentication; no market-data request was made.

## Documented behavior

The v3 REST bars endpoint accepts `firstdate`/`lastdate`; `firstdate` excludes `barsback`. Specify `unit=Minute` and `interval=1`. The streaming endpoint has a different parameter list and is not interchangeable with the REST acquisition request. `IsEndOfHistory` concerns completion of historical delivery; `BarStatus` concerns whether a bar is open or closed. The REST example includes closed bars with `IsEndOfHistory=false`, so this combination is valid. `IsRealtime` is another distinct field. The shared timestamp schema specifies RFC3339 formatting, without establishing minute interval start/end labeling. Symbol details are available through `/v3/marketdata/symbols/{symbols}`. [TradeStation API specification](https://api.tradestation.com/docs/specification/)

The intraday response cap is 57,600 bars. Date-range requests span at most three calendar years. The overall bars limit is 500 requests per five minutes. Date-range history credits use calendar-day span plus one, divided by 365, rounded down to two decimals; charges at or below 0.25 credits count as zero. Capacity and replenishment are 200 credits and 200 credits/minute respectively. Seven-day chunks plus overlap fit comfortably within these limits. Limits are capacity constraints, not a price quotation; other clients may share the quota. Execute serially at the ledger's conservative schedule, retaining 429 responses and retry boundaries. [Historical bar limits](https://api.tradestation.com/docs/fundamentals/rate-limiting/historical-bar/)

TradeStation's individual futures syntax uses root, month code and two-digit year; its June E-mini example uses `M`. The provider lists `MNQ` for Micro E-mini Nasdaq-100 futures. Thus **MNQM25 is the candidate spelling**, inferred from those conventions. This does not verify that the API currently serves the expired June 2025 contract or that this account has access. Do not substitute a continuous symbol or the installed September 2026 symbol. [Futures symbology](https://help.tradestation.com/09_05/eng/tradestationhelp/symbology/futures_symbology.htm), [TradeStation symbol table](https://www.tradestation.com/learn/market-basics/futures-options/symbology/futures-plus-symbology/)
